Depois do jailbreak + GoldHEN. Caminho mais facil: HB-Store primeiro.

COMO INSTALAR (resumo):
1) GoldHEN ja carregado.
2) Abre o link "Instalar HB-Store" abaixo (fica na PS4).
3) Ou: mete o .pkg no USB → Definicoes → Debug Settings → Package Installer → usb:/
1. Homebrew Store (PKG-Zone)
Loja free (LightningMods). Melhor ponto de partida. Daqui instalas o resto.
recomendado · free
Instalar HB-Store na PS4 (com GoldHEN) Pagina explicativa HB-Store
2. Itemzflow
Gestor de jogos / menu. Depois da HB-Store, procura Itemzflow la dentro e instala.
free · open source
Abrir Itemzflow no PKG-Zone
3. FPKGi
Instalador de PKGs com listas JSON. Baixa o .pkg no telemovel/PC, mete no USB, instala com Package Installer. (GitHub no browser da PS4 costuma falhar.)
free · open source
Download FPKGi (PC / telemovel)
4. FPKGi+
Lista curada de homebrew (emuladores, Apollo, etc.). Sem jogos. Usa depois de teres FPKGi.
free · brewology
Abrir FPKGi+ no Brewology

Package Installer (USB)

  1. GoldHEN carregado + FW Update Block ligado.
  2. USB exFAT ou FAT32 com o ficheiro .pkg na raiz.
  3. Definicoes → (GoldHEN) Debug Settings → Game → Package Installer.
  4. Escolhe usb:/ e o .pkg.
