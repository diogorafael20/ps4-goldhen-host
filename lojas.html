Como instalar um PKG

  1. GoldHEN carregado (FW Update Block ligado).
  2. USB exFAT/FAT32 com o .pkg na raiz ou Remote Package Install.
  3. Definições → ★ GoldHEN ★ / Debug Settings → Game → Package Installer.
  4. Fonte: USB usb:/ (ou HDD /data/pkg).
